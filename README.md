# @espadat/docs-theme

Shared Starlight theme for Espadat tool documentation sites.

Consumed as a pinned git dependency:

```json
"@espadat/docs-theme": "github:espadat-studio/docs-theme#v0.1.0"
```

Consumers: [auberge](https://auberge.espadat.com), [dublette](https://dublette.espadat.com), [colporteur](https://colporteur.espadat.com).

The design system it carries is defined in `espadat.com` — see
[ADR-0001](docs/adr/0001-tool-docs-are-starlight-on-subdomains-themed-by-a-shared-package.md)
for why this repo exists and what it deliberately does not do.

AGPL-3.0-or-later.
